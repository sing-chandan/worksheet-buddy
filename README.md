# Worksheet Buddy

Static, mobile-friendly quiz player with seven prepared Grade 2 worksheets, Hindi translations, device pronunciation and JSON import/export.

## GitHub Pages

Upload these files at the repository root. In Settings → Pages, choose Deploy from a branch → main → / (root), then Save. GitHub shows the live URL after publication.

This static version plays prepared quizzes without an AI API. Automatic AI generation and Google Drive sync are not connected. Practice and edits are stored in each browser. Hindi speech needs an installed Hindi voice.
